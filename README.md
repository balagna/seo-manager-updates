# SEO Manager Updates

Canal oficial de actualizaciones de SEO Manager.

Los paquetes se distribuyen mediante GitHub Releases y SEO Manager
verifica SHA-256 antes de instalar una actualización.

## Política de releases

- Los releases publicados son inmutables.
- Nunca se reemplaza un ZIP publicado bajo el mismo nombre.
- Si cambia un paquete se genera una nueva revisión: r2, r3, etc.
- El SHA-256 debe coincidir con manifest.json.
- SEO Manager mantiene respaldo y rollback antes de actualizar.
